数据说明

数据来源

各高校双选会数据仅来自对应高校自己的就业官网 / 官方就业平台（新锦成、云就业、就业宝等校专属子域），已按每校域名白名单校验，杜绝跨校串源；第三方聚合站（如 24365 广西毕业生就业网通用页）不用于收录高校条目。

收录范围

只收录「举办日期 ≥ 今天」且已正式公布的场次；未明确信息（时间 / 地点待定）一律标注，不猜测。「桂林市现场招聘会」栏目收录非校园场地（人才市场 / 会展中心 / 产业园 / 广场等）的线下招聘会，面向毕业生 / 校招的场次优先展示。

更新机制

每日 08:00（北京时间）由 GitHub Actions 自动抓取各校官网，有新增或变更时自动更新并部署；每日 19:00 邮件推送未来 7 天场次提醒。
